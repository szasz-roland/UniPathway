# Security Policy

This is a small personal static web app with no backend, no user accounts, and no data collection (Phase 1). Threat surface is minimal, but if you find a security issue:

- Preferred: open a [private security advisory](../../security/advisories/new) on this repo (GitHub Security tab → "Report a vulnerability") rather than a public issue.
- Please don't open a public issue for anything that could be actively exploited before a fix ships.

Once Phase 2/3 introduces a backend, authentication, or push notifications, this policy will be updated accordingly.
